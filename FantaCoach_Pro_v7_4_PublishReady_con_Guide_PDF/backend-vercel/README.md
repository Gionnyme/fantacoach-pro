# Backend FantaCoach per Vercel

1. Crea un progetto Vercel con questa cartella.
2. In Settings > Environment Variables aggiungi:
   API_FOOTBALL_KEY = la tua chiave API-Football
3. Deploy.
4. Copia l'URL HTTPS del progetto dentro FantaCoach > Guida API > URL backend.

Endpoint:
- /api/sync
- /api/matchday

La chiave resta sul server e non viene inclusa nell'app Android.
