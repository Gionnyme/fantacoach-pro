FantaCoach Pro v7.5 - Come creare l'APK

Prima regola: estrai lo ZIP. Non caricare lo ZIP chiuso su GitHub.

1. Carica il repository

Nella pagina principale del repository devono comparire .github, android, backend-vercel e web-source.

2. Controlla il workflow

Apri .github/workflows/crea-apk-android.yml. Se il file esiste, GitHub riconosce il workflow.

3. Avvia la compilazione

Apri Azioni. A sinistra seleziona Crea APK Android. Premi Esegui flusso di lavoro, scegli main e conferma.

4. Scarica l'APK

Quando la compilazione è verde, apri l'esecuzione e scarica l'artefatto FantaCoach-Pro-v7.5-APK. Dentro trovi FantaCoach-Pro-v7.5.apk.

Se non compare Crea APK Android: usa la cartella SE_NON_COMPARE_LA_VOCE_AZIONI inclusa nel pacchetto.
